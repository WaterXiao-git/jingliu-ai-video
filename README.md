# 镜流 · AI 短剧工作台

在自己的电脑上把剧本拆成分镜，用参考图生成镜头，然后配字幕、配音，导出 MP4。部署工具先检查硬件、驱动和磁盘空间，再让你决定是否安装。

## Windows 快速开始

1. 在本仓库选择 **Code → Download ZIP**，把压缩包完整解压到有空间的磁盘。也可以使用 Git 克隆。
2. 双击 **打开镜流.cmd**，选择「检查这台电脑」或「检查并安装」。首次安装会显示目标位置、下载量和计划编号。
3. 阅读 H3 许可并确认安装计划。安装完成后会跑一次短镜验证，随后打开本机工作台。
4. 点「新手引导」，导入「月台机器人」练习项目。先生成一个短镜头，再尝试添加字幕和导出。

首发安装目标为 Windows x64 和 NVIDIA CUDA。已验证机器是 RTX 4060 Laptop 8GB、16GB 内存。全新安装预留约 **35 GiB**，连同本地编剧模型约 **45 GiB**。五个视频权重共约 **22.2 GB**。已有匹配的 ComfyUI 环境可复用。

## 交给 Agent 安装

把仓库链接和这句话发给有本机终端权限的 Agent。

> 请使用这个仓库的 ai-video-deployer Skill，在我的电脑上先做只读检查。告诉我预计下载量、安装目录和硬件差距，等我确认后再安装并验证出片。

Windows、Linux 和 macOS 上都可以运行只读 Doctor。Linux、macOS 的一键安装仍需验证，报告会给出替代选项。

## 许可与数据

硬件检查和创作素材由你的电脑处理。启用 Edge TTS 时，会将选定台词发送给语音服务。分享卡可以预览后主动下载，提示词需单独勾选。工作台的服务监听本机地址。
