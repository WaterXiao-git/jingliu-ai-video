# Windows 自动检测安装入口验收

版本：0.1.5-preview.2。测试日期：2026-11-24。

本次修改启动中心的自动选择与交互，视频引擎和模型未变更。

## 已验证

- Windows 上运行全部 30 项单元检查通过。其中 C# 检测程序使用独立临时目录验证 8 个情形：旧路径失效、显式路径优先、数据盘选择、可选编剧空间预算、空间不足提示、中文路径 ComfyUI 发现、安装中断续用、禁用不兼容复用后的独立安装选择。
- 本机 EXE 的 `--detect` 未指定部署目录，自动发现原有部署，保留工作台端口和编剧配置。未复制模型或 Python 环境。
- EXE 在一个仅用于计划检查的临时目录自动准备安装计划。全程未填写技术参数，检测显卡、驱动、显存、物理内存、提交余量、磁盘和中文声线；显示下载量和预算。只写入约 6 KB 计划文件，未点击安装或下载模型。
- 原生界面默认隐藏目录、端口等编辑控件；已部署状态隐藏安装许可勾选和安装按钮。展开高级设置可完整查看原有部署入口，已检查高 DPI 显示。
- EXE 缓存完整性、ZipSlip 防护、必要资源、现有工作区就绪自检通过。

## 范围

这是自动发现、计划和界面的验收，没有重新执行数十 GB 的第二套模型安装，也没有重跑视频采样。[此前真实 H3、配音、字幕与 MP4 验收](2026-11-24-win-exe/index.md)继续作为视频流水线的证据。另一台实体电脑的完整安装仍需验收。

自动发现只查找已知目录，不扫描全盘；未找到自定义位置时可通过高级设置选择。初始地区为 CN，用户仍需核对实际地区并接受模型许可。
