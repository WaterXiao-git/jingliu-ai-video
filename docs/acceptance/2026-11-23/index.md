## 国内链路与验证范围

下载实际涉及 Gitee、华为云、阿里云、上海交大、魔搭和 CNB 的分发服务。下载器校验每次重定向；pip 子进程默认启用域名守卫。完整验收另给 Python 安装与生成进程启用了 DNS / socket 审计，记录中没有境外域名请求或被拒绝的连接。Ollama 关闭云模型功能，使用本地 GGUF 注册模型，运行中观察到本机回环连接。

域名列表和校验值见 result.json。原始进程审计、安装日志与 ComfyUI 日志保存在验收机器的运行目录中。审计范围是本项目安装和生成进程，不包括操作系统及其他软件的后台流量。维护项目时查询上游资料、核对官方摘要和发布代码，属于项目维护步骤，不是用户安装时的资源依赖。

## 本次发现并修复

- 原 Python EXE 静默安装停滞，改用核对官方摘要的 NuGet 包解压部署，正常创建独立虚拟环境。
- 全新环境自带 setuptools 65.5.0，低于固定 PyTorch 的要求，补入 setuptools 78.1.0 后 pip check 通过。
- 文字编码器改为魔搭 Comfy-Org 转换版本，完成实际 H3 出片验证；旧版确切哈希仍列为可复用项。
- Ollama GPU 编剧探测长时间未返回，默认改为 CPU 编剧；GPU 编剧不计入通过项。
- 增加中文离线声线预检，避免下载大量模型后才发现系统配音条件不足。

## 性能与边界

本次 H3 冷启动执行耗时 **21 分 18 秒**，其中 20 步采样约 18 分 06 秒。生成时显卡报告约 210MHz 核心频率及功耗限制，系统内存余量较低。本次证明流程可用，速度应以目标机器的实际状态为准。

该样片用于功能验收，不是 30 秒正式短剧。720×1280 成片由 320×576 试拍源缩放导出。离线系统声线与 Edge 神经声线的音色不同。本次是在同机独立目录验收，另一台实体机器以及 Linux、macOS 的完整视频部署仍需分别实测。
