# Agent 技能连接器修复验收

版本：v0.1.5-preview.4，日期：2026-11-28。

- 服务端素材接口支持部分更新：只改名称时保留类型、参考图、提示词和声线；显式空字符串可清除可选字段。CLI 先读取并合并素材，兼容旧版工作台的整条覆盖接口。
- wait 保留 stdout JSON，完成/失败/取消/超时分别返回 0/3/4/124，失败同时写 stderr。采用单调时钟并限制轮询间隔，超时不会取消原任务。请求错误为 1，参数解析错误为 2。
- 仓库根目录新增 scripts/jingliu.py 转发入口。独立技能仍可单独安装，并使用脚本绝对路径调用；文档明确工作目录与任务状态处理。
- 下载流式写入同目录临时文件后替换，支持自动创建输出目录，常见连接和文件错误返回友好提示。
- 独立技能 ZIP、Windows 便携包和 EXE 内置程序均携带相同技能资源。mock 媒体路径与导出字段已对齐真实工作台，旧式素材覆盖行为保留用于验证 CLI 的向后兼容性。

本机 62 项检查通过，包含真实 aiohttp 工作台接口：素材字段保留与显式清空、CLI 调用和真实媒体下载、终端任务退出码；超时和旧服务兼容性由受控服务验证。CI 安装轻量工作台测试依赖，确保真实接口检查实际执行。

真实 CLI 完成建项目、图片上传、角色修改、分镜、本地中文女声、字幕、2 秒 720×1280 MP4 导出及 MP4/SRT 下载；FFmpeg 全流解码通过。改名后 image/prompt/voice 全部保留，failed/cancelled/timeout 退出码确认为 3/4/124。

未新建模型环境、下载模型或重跑 H3 采样，原始本机工作流未修改。本轮验证 CLI 与工作台接口，不声称已完成 WorkBuddy/zcode 等客户端的自动发现与触发验收。原有 H3 生成验收见此前报告。
