- 从该独立源码构建 Windows EXE 成功，构建记录标记源码干净。EXE 在仅含系统目录的 PATH 下完成必要资源、缓存完整性和 ZipSlip 自检，不依赖 PATH 中的 Python、Git 或 Node.js。

- 实际完成 2 秒参考图装配、本地中文女声、字幕和 720×1280 MP4 导出；通过音视频流检查与 FFmpeg 全流解码。该测试使用内置参考图，不冒充新生成的 H3 镜头。

## 范围与限制

本次验证线上拉取、构建、图标、自动检测、工作台接口和本地导出；没有重复执行数十 GB 的全新安装或 GPU 采样。[此前真实 H3、配音、字幕和 MP4 的验收](2026-11-24-win-exe/index.md)仍是 GPU 流水线证据。另一台实体电脑、干净 Windows 和不同显卡仍需分别验收，不能据此承诺所有电脑都无问题。

清理开发机副本前，需确认 GitHub、Gitee 的代码引用一致，发布附件可下载且 SHA-256 匹配；仅清理公共项目、测试和程序缓存，保留最初的本机工作流、模型、素材与成片。
